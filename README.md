# Christmas Tree

A shared Christmas tree on the web. Friends open your tree's link, make an ornament, hang it anywhere on the tree, and leave a note. An optional Windows widget keeps your tree in a corner of your screen.

The interface is in Korean.

## Features

- **Ornaments**
  - Pick one of 8 shapes, then choose any color, a pattern, and a secondary color.
  - Or draw your own ornament on a 16×16 pixel canvas.
  - Every ornament can have engraved text (up to 3 characters), a size, a rotation, and a shine effect.
- **Notes**: Leave a note with each ornament. Hover over or tap an ornament to read its note.
- **Your own tree**: Anyone can create a tree and share its link. No sign-up needed.
- **Snow**: Let it snow on the tree for a minute.
- **Desktop widget**: A transparent, always-on-top tree for Windows that updates live.

## Decorating a tree

- Open the tree link you received.
- Make an ornament: pick a shape or draw one, then decorate it.
- Tap the tree where you want to hang it.
- Enter your name, write a note, and hang it.
- You can hang up to 3 ornaments per tree, and you can remove the ones you hung.

## Creating your own tree

- Press **나도 트리 만들기** (Make my own tree) and give your tree a name.
- Share the link with friends so they can decorate it.
- The browser you created the tree in becomes its owner. As the owner, you can:
  - copy the share link
  - rename the tree
  - remove any ornament
- To manage the tree from another device, open its **manage link** there. Keep this link to yourself.

## Desktop widget (Windows)

**Install**

- Download `TreeWidget-Setup-<version>.zip` from [Releases](../../releases).
- Extract it and run `TreeWidget-Setup-<version>.exe`. No administrator rights are needed.
- The installer is not code-signed. If Windows SmartScreen warns you, choose **More info → Run anyway**.
- On first launch, enter your tree's link.

**Use**

- **Open the site**: Click the tree.
- **Move**: Press and drag the tree. It snaps to screen edges and remembers its position.
- **Resize**: Hold Ctrl and scroll over the tree (55–220%).
- **Read notes**: Hover over an ornament.
- **Tray menu**: Right-click the tray icon to set the position, size, monitor, snow, and start with Windows, or to change the tree link.

**Update and uninstall**

- **Update**: Run a newer installer. Your settings are kept.
- **Uninstall**: In Windows **Settings → Apps**, remove "크리스마스 트리 위젯".
